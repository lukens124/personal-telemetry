# Google 雲端同步設定

約 5 分鐘，只需做一次。

1. 到 Google 雲端硬碟新建一份 Google 試算表，命名為 `Personal_Telemetry_DB`。
2. 選單 **擴充功能 → Apps Script**，刪掉預設內容，貼上 [`gas/Code.gs`](../gas/Code.gs) 的全部內容，按儲存。
3. 上方函式下拉選 **setup**，按 **執行**。
   - 第一次會要求授權：選你的帳號 → 進階 → 前往（不安全）→ 允許。這是你自己的腳本，只存取這份試算表。
   - 執行完到下方 **執行記錄** 複製 `SYNC TOKEN:` 後面那串字。
4. 右上 **部署 → 新增部署作業** → 齒輪選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按部署，複製 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）
5. 在 App 點右上 ⚙️ → 貼上網址與 Token → **連線並同步**。

## 備註

- 「所有人」是指網址可被呼叫，但沒有 Token 的請求一律拒絕。網址和 Token 請勿公開。
- 試算表三個分頁 Habits / Containers / Habit_Logs 可直接檢視或分析，但**請勿手動修改或刪除列**，修改請在 App 內進行。
- 之後若更新 `Code.gs`：部署 → 管理部署作業 → 編輯 → 版本選「新版本」，網址不變。
- 新手機：安裝 App 後在設定貼上同一組網址與 Token，會自動從雲端還原。
- 忘記 Token：在 Apps Script 執行 `showToken`。
