# 社團雲端：管理者手冊

你的試算表同時是社團雲端。成員用你給的**邀請連結**加入，每個人只能讀寫自己的資料；你看得到全部。

## 更新腳本（只做一次）

1. 試算表 → 擴充功能 → Apps Script → 全部刪除，貼上 [最新的 Code.gs](https://raw.githubusercontent.com/lukens124/personal-telemetry/main/gas/Code.gs) → 儲存
2. 執行 **setup**（會新增「成員」與「設定」兩個分頁；既有資料不受影響，仍然屬於你）
3. **部署 → 管理部署作業** → 鉛筆 → 版本：**新版本** → 部署（網址不變）
4. 「設定」分頁：**B1** 貼上網頁應用程式網址（`…/exec`）；**B3** 可填社團名稱，成員的 App 會顯示

## 邀請成員

1. 「成員」分頁 **A 欄**（第 2 列起）填上名字，一人一列
2. Apps Script 執行 **createInvites**
3. **E 欄**會出現每個人的專屬邀請連結 → 私訊給對方

成員第一次打開 App 選「加入社團雲端」並貼上連結就完成；之後換手機，用同一條連結即可還原。

## 停用成員

把該列 **D 欄「狀態」** 從 `ACTIVE` 改成 `REVOKED`，對方立即無法再同步（手機上已有的資料仍在他自己手機裡）。
要刪除他的雲端資料：在三個資料分頁篩選 `owner_id` = 他的成員 ID（B 欄），刪除那些列。

## 你看得到什麼

- Habits / Containers / Habit_Logs 三個分頁中，`owner_id` 欄標示擁有者：空白 = 你自己，`m_xxxx` = 對應「成員」分頁 B 欄
- 「成員」分頁 G 欄是每個人最後一次同步的時間

## 對成員的承諾（App 內已告知）

- 管理者看得到成員的全部紀錄；成員之間看不到彼此
- 成員可隨時停用同步，或請你刪除他的資料

## 注意

- 邀請連結等同該成員的鑰匙：外流時把那一列改成 `REVOKED`，再新增一列同名成員重新產生
- 10 人以內沒問題；人數或資料量大很多時，同步會變慢
