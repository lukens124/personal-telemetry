# 把資料存在自己的 Google 雲端

設定一次，約 5 分鐘。完成後紀錄會自動備份到**你自己的** Google 試算表，只有你看得到。

> 建議用電腦操作。瀏覽器若同時登入多個 Google 帳號容易出錯，可以開**無痕視窗**、只登入要用的那個帳號。

## 1. 建立試算表並貼上程式

1. 打開 [Google 試算表](https://sheets.new)，建立一份新的試算表，命名例如 `我的遙測資料`
2. 上方選單 **擴充功能 → Apps Script**
3. 把編輯器裡原本的內容全部刪掉
4. 打開 [這個連結](https://raw.githubusercontent.com/lukens124/personal-telemetry/main/gas/Code.gs)，全選複製，貼回編輯器
5. 按 💾 儲存

## 2. 執行 setup

1. 編輯器上方「▶ 執行」旁的下拉選單選 **setup**，按 **執行**
2. 第一次會要求授權：選你的帳號 → **進階** → **前往（不安全）** → **允許**
   （這是你自己的程式，只會存取這份試算表）

## 3. 部署

1. 右上 **部署 → 新增部署作業**
2. 左邊齒輪 ⚙️ 選 **網頁應用程式**
3. 執行身分：**我**；誰可以存取：**所有人**
4. 按 **部署**，複製「網頁應用程式網址」（`…/exec` 結尾）

> 「所有人」只代表這個網址能被呼叫；沒有你的 Token 的請求一律會被拒絕。

## 4. 產生配對連結

1. 回到試算表，打開下方的 **設定** 分頁，把剛才的網址貼到 **B1**
2. 回到 Apps Script，下拉選單選 **showPairing** → 執行
3. 「設定」分頁的 **B4** 會出現你的配對連結（執行記錄裡也有）

## 5. 連到 App

把配對連結傳到手機（LINE、備忘錄都可以），貼進 App：

- 第一次打開 App：選「存在我自己的 Google 雲端」→ 貼上 → 連線
- 已經在用：右上 ⚙️ 設定 → 配對連結 → 貼上 → 連線並同步

之後其他裝置在設定頁的「新增裝置」就能取得連結，不用再重做以上步驟。

**配對連結等同你雲端的鑰匙，只傳給自己的裝置。**

## 常見問題

| 狀況 | 解法 |
|---|---|
| 打開 Apps Script 顯示「無法開啟檔案」 | 瀏覽器登入了多個 Google 帳號：改用無痕視窗、只登入一個帳號 |
| showPairing 顯示「找不到網頁應用程式網址」 | 還沒部署，或「設定」分頁 B1 沒貼網址 |
| App 顯示「Token 不正確」 | 重新執行 showPairing，用新產生的連結 |
| 想看自己的資料 | 直接打開試算表：Habits（項目）、Containers（清單）、Habit_Logs（紀錄）。請勿手動修改或刪除列 |
